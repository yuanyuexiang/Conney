# Relay 项目工作量与费用评估

**项目名称：** 汽车供应链邮件数据采集与交付计划管理平台  
**编制日期：** 2026年11月4日  
**文件性质：** 初步预算评估，供范围及商务讨论使用，非最终固定报价。

## 一、项目目标

自动从263企业邮箱采集交付计划Excel附件，完成原件归档、数据解析、校验、计划版本管理和差异查询，减少人工下载及整理工作，并保留数据来源以便追溯。

当前已分析五种原始附件模板：Vitesco DELFOR、DRX DELFOR、JLR DELFOR、JLR DELJIT和Kroschu 4905。已有样本能够支持解析设计，业务代码解释及版本差异验收仍需补充资料。

## 二、交付范围

1. **邮箱采集：** 263邮箱连接配置、指定文件夹增量同步、筛选规则、断线重连及失败重试；采集不改变邮件已读状态，不移动或删除邮件。
2. **附件管理：** 原始文件归档、哈希去重、处理状态、鉴权下载及来源追溯。
3. **数据解析：** 对约定的`.xlsx`模板提取文档头、全部物料块及数量记录，处理日期点、日期区间、零值和特殊记录，展示校验问题。
4. **计划管理：** 按确认的业务规则保留版本快照，展示数量、日期和状态等变化；无法确认的匹配结果明确标记。
5. **管理后台：** 运行概览、邮箱、邮件、附件、计划及差异查询，基础管理员和查询用户权限。
6. **部署交付：** 一套运行环境、部署文档、操作说明、基础日志监控、备份配置及恢复验证。

采用Python后端、Web管理后台和PostgreSQL数据库。API与Worker独立运行，共用业务逻辑；不依赖大模型进行业务数据解释。

## 三、本期不包含

- 人工需求调整台账、欠交补入、延期调配和手工数量增减。
- 自动生产排程、空海运分配及运输计划计算。
- 自动生成或逐格复现《德科需求.xlsx》人工处理结果。
- ERP、MES、WMS对接，外部系统专用接口开发。
- OFTP2/AS2通信、通用EDI网关及EDI回传。
- 未约定模板、`.xls`等新增格式、复杂历史数据清洗。
- 单点登录、复杂组织权限、高可用集群及全天候值守。

## 四、工作量与工期

**计划交付周期：1个月。** 自双方确认的开工日起计算，具体开工及验收日期在合同中明确。以下按4个工作周安排，节假日及实际工作日纳入开工排期。

| 时间安排 | 工作内容 | 交付及检查结果 |
| --- | --- | --- |
| 第1周：基础搭建与邮件采集 | 核对并冻结字段映射及验收样本；搭建工程、数据库和后台框架；接通263邮箱，完成增量同步、附件归档；启动模板解析 | 可采集约定邮件并下载原件，保存来源及处理状态；字段和业务规则有明确确认记录 |
| 第2周：五种模板解析与数据查询 | 完成Vitesco、DRX、JLR DELFOR、JLR DELJIT、Kroschu五种模板解析、校验及回归测试；完成邮件、附件、物料块和原始数量查询 | 样本字段、物料块及数量记录可核对，日期区间和特殊值保留，异常有明确位置 |
| 第3周：版本差异与系统联调 | 完成计划版本、差异比较、任务重试、基础权限及计划查询；部署客户云服务器，开展完整流程联调 | 系统达到约定试运行条件；业务人员使用连续版本样本核对差异结果 |
| 第4周：试运行与验收交付 | 客户试用、问题修复、备份恢复验证、操作培训及文档整理 | 完成约定功能和样本验收，交付系统、部署及操作文档 |

采集、解析、前端页面和测试按依赖关系交叉推进，周计划表示主要交付检查点。工作量仍初步估算为**35～50人日**，为累计投入，不等同于日历工期；一个月交付需要相应并行资源，具体人员及支援安排须在开工前落实，当前不作为已确定的人员配置。

### 客户配合与工期前提

- 开工前确认五种模板范围、字段及代码含义、数量口径、版本规则和验收标准，并提供连续版本及必要异常样本。
- 客户云服务器、263邮箱及必要网络权限具备测试条件，双方已确认排期和启动款。
- 指定有决策权限的业务验收人，原则上在1个工作日内反馈阻塞问题，第3周参与核对、第4周集中验收。
- 新增需求另行评估开发费用与工期。资料、权限或反馈延误时，双方根据实际影响确认调整日期。
- 开工前核验人员容量及任务依赖；若资源或关键输入不足，须先调整排期或协商范围，不能通过省略验证满足日期。

| 项目 | 交付内容 | 预算区间 |
| --- | --- | ---: |
| Relay 平台整体开发交付 | 263邮箱采集、五种约定模板解析、附件管理、计划版本及差异、管理后台、客户云服务器部署、测试及交付文档 | **7万～9万元** |

## 六、验收与试运行

- 以双方确认的模板清单、字段映射、代码规则、连续版本样本及功能清单验收。
- 校验样本中的物料块和原始数量记录完整提取，编号、数量、日期及来源准确；异常有明确定位。
- 验证重复同步、任务重试及重新解析不产生重复业务版本。
- 版本差异须与业务人员核对一致；缺少规则或连续版本样本的模板，相关差异功能不能视为已验收。
- 试运行期间保留现有人工流程，观察同步延迟、解析失败率、任务积压及异常处理结果；具体时效指标在了解实际处理量后确定。
- 出现问题可暂停采集或回退应用版本；涉及数据库变更时按迁移及备份恢复方案执行。系统不直接修改客户ERP或生产计划。

## 七、客户需提供的资料与配合

| 项目 | 所需内容 |
| --- | --- |
| 范围确认 | 五种模板是否全部纳入，是否存在其他客户或格式 |
| 版本样本 | 每种拟验收模板，同一业务计划连续至少3次收到的原始附件，优先包含数量或日期变化 |
| 业务规则 | 字段及代码说明、累计与单期数量关系、替换/增量规则、零值及取消含义、DELFOR与DELJIT关系 |
| 邮箱权限 | 263 IMAP配置、认证方式、文件夹及网络访问限制，管理员协助连接测试 |
| 规模与时效 | 日常邮件量、附件大小、历史同步范围、用户数量及更新时效要求 |
| 部署与验收 | 客户云服务器配置、备份位置、运维负责人及具备确认权限的业务验收人 |

建议客户安排一位固定业务负责人，每周集中确认问题，并在约定时间内反馈。仅提供必要访问权限；凭据通过安全渠道交付，资料按约定脱敏且保留结构、编号对应关系及数量变化关系。

## 八、部署环境与后续开发

- **部署环境：** 使用客户已有云服务器，不另行报价云服务器采购或月度托管费用。开工前检查操作系统、CPU、内存、磁盘、网络、域名及证书条件，并确认备份位置和访问权限。
- **部署工作：** 本期开发预算包含一套客户云服务器环境的应用部署、配置、备份恢复验证及交付文档。
- **资源费用：** 客户现有云资源的续费及实际存储、网络、备份等支出由客户自行承担。如需扩容或新增资源，先说明需求及费用影响，由客户确认采购。
- **模型调用：** 当前方案无需大模型调用费用。
- **验收后缺陷支持：** 建议包含最终验收后30天内，对已确认范围中实现缺陷的修复，具体边界在合同中约定。
- **后续需求：** 本次不报价年度维护包。后续新增需求、模板或功能改动按实际开发范围另行评估工作量、开发费用和交付时间，确认后实施；不设置固定维护服务费。

## 九、变更及最终报价条件

新增客户模板、格式、字段口径、页面、权限、接口、部署环境或历史处理范围，应先评估对费用与工期的影响，经双方确认后实施。

现有模板中因实现不符合已确认规则造成的问题属于缺陷；客户或上游调整模板结构、业务含义或验收标准，属于变更。未知代码和特殊记录不通过猜测解释，须由客户确认后进入业务计算。

最终报价前需确认：五种模板的具体交付范围、连续版本资料、业务规则、验收负责人、1个月交付对应的开工及验收日期、并行人员和测试支援、客户云服务器条件及预算。项目承诺以可验证的采集、解析、查询和差异结果为边界，不承诺未经测量的人工成本节省或生产经营结果。
